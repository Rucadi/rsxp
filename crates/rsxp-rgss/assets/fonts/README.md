# ArcadeNeon fonts

These typefaces are embedded by `crates/rsxp-rgss/src/ui/theme.rs` so the
desktop, browser, and Android frontends share identical typography.

| File | Family | Source |
| --- | --- | --- |
| `Bungee-Regular.ttf` | Bungee | <https://github.com/google/fonts/tree/main/ofl/bungee> |
| `WorkSans.ttf` | Work Sans (variable) | <https://github.com/google/fonts/tree/main/ofl/worksans> |
| `SpaceMono-Regular.ttf` | Space Mono | <https://github.com/google/fonts/tree/main/ofl/spacemono> |

All three families are licensed under the SIL Open Font License 1.1. The
matching `*-OFL.txt` files are included alongside the fonts. See `DESIGN.md` at
the repository root for the design system that consumes them.
